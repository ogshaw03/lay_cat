# 3D マネキン（ポーズ指示）機能 設計メモ

近日実装予定。アノテーションレイヤーに 3D マネキンを配置し、ポーズを付けて絵のアタリ／レビュアーのポーズ指示に使える機能。

---

## 目的・想定ユーザー

- **絵を描くときのアタリ**：アニメーター／作画スタッフが構図・パースの当たりとして使う
- **絵が描けないレビュアーのポーズ指示**：演出・監督・クライアントが「こう動いてほしい」を言葉ではなく形で示す

つまり「言葉と落書きの中間」を埋める道具。

---

## 実装アプローチ

### レンダリング

- **Three.js** を使用（アノテーションレイヤーに `<canvas>` 追加）
- モデル形式：glTF 2.0（`.glb` 推奨・単一ファイル・ボーン込み）
- 単一 HTML アプリの自己完結性を崩さないよう、Three.js は base64 埋め込み or CDN のいずれか（要検討）

### ポーズ操作 UI

- OrbitControls：カメラ回転・ズーム
- ボーン選択 → 回転ギズモ（Three.js の TransformControls）
- 必要なら簡易 IK（`three-ik` or 自前）で「手首を掴んで引っ張る」操作

### 保存フォーマット

- アノテーション JSON に以下を追加：
  ```json
  {
    "type": "mannequin",
    "modelId": "male_adult",
    "transform": { "pos":[x,y,z], "rot":[qx,qy,qz,qw], "scale":s },
    "pose": { "spine":[qx,qy,qz,qw], "leftArm":[...], ... },
    "cameraView": { "pos":[x,y,z], "target":[x,y,z] }
  }
  ```
- フレーム連動：既存アノテーションと同じくフレーム単位で保持
- 補間：将来的にフレーム間でポーズ補間して簡易プレビズ化する余地あり

---

## モデル保存場所

**方針：リポジトリ同梱（`assets/mannequin/`）**

理由：
- 全プロジェクト共通の共通アセット・ユーザーがアップロードするものではない
- 1〜3 個のプリセット（成人男・成人女・子供）なら合計 5〜15MB
- GitHub Pages で配信十分・ブラウザキャッシュに載れば以後即時
- LayCAT のバージョン管理と一体化（マネキン更新＝リポジトリコミット＝全ユーザーに配信）
- BYO R2 ユーザーの Worker 設定に依存しない
- `laycat.html` 本体には埋め込まない（10MB 超えると開くだけで重くなるため）

### 提案パス構成

```
assets/mannequin/
  ├── male_adult.glb         (~2-4 MB)
  ├── female_adult.glb       (~2-4 MB)
  ├── child.glb              (~1-2 MB)
  ├── thumbs/                # UI 表示用サムネ
  │   ├── male_adult.png
  │   ├── female_adult.png
  │   └── child.png
  └── manifest.json          # 利用可能モデル一覧・デフォルトポーズ
```

`manifest.json` を挟むと、モデル追加時にコード変更不要で UI に出せる。

### 将来の拡張

- **ユーザー持ち込みマネキン**（オリジナルキャラの T ポーズ glTF 等）はプロジェクト単位で R2/ローカルに保存
- 共通プリセット（リポジトリ）＋ プロジェクト固有（R2）の二層構造にする

## モデル調達方針

- **フリー商用可の glTF**（例：Mixamo の T ポーズキャラを glTF 変換／Poly Haven／自作）
- ライセンス表記が必要な場合は intro/guide のクレジット欄に追記
- 顔テクスチャなしのニュートラル体型が望ましい（キャラ性を持たせない）

## UI 案

### アノテーションツールバー
- 既存の 筆・消しゴム・矢印 の並びに **[マネキン]** ボタンを追加
- クリックでモデル選択ドロワー（プリセット 3 種）を開く

### マネキン操作モード
- キャンバス上でドラッグ → カメラ回転
- ボーンクリック → 選択・ギズモ表示
- 右パネル：プリセットポーズ（立ち・座り・振り向き・煽り視点向け）
- Shift + ドラッグ → 平行移動、Ctrl + ドラッグ → スケール

### 静止画への焼き込み
- 完成したポーズは最終的にアノテーション PNG に焼き込むか、3D データとして保持し続けるか要検討
  - **案 A**：3D として保持 → 再編集可能・ファイル軽量・要 Three.js 常駐
  - **案 B**：PNG 焼き込み → 再編集不可・軽量表示・Three.js は編集時のみ
  - **推奨**：案 A＋案 B ハイブリッド（内部は 3D 保持、表示時は PNG キャッシュ）

## 懸念点・課題

1. **スマホ操作性**：ボーン選択・回転ギズモはタッチデバイスでかなり厳しい → 「ポーズは PC 編集・スマホは閲覧のみ」割り切りが現実的
2. **ファイルサイズ**：3 モデル × 3MB = 9MB 追加。GitHub Pages の帯域を圧迫しないか要監視
3. **Three.js の base64 埋め込み**：本体 ~600KB を base64 化すると ~800KB。laycat.html に混ぜるか、`assets/three.min.js` として別置きするか要判断
4. **IK 品質**：シンプルな FK（ボーン個別回転）で始め、需要が固まってから IK 導入
5. **既存アノテーションレイヤーとの共存**：筆で描いた線とマネキンの前後関係をどう扱うか（マネキン後ろに描画 or マネキン後ろにレイヤー）

## 実装ステップ案

### Phase 1（MVP）
- Three.js 導入・単一マネキン glTF ロード
- カメラ回転・ボーン単純回転（FK のみ）
- 4 プリセットポーズ（立ち・座り・T ポーズ・振り向き）
- アノテーション JSON に 3D データ保存

### Phase 2
- 複数モデル切替（成人男・成人女・子供）
- ポーズプリセットライブラリ拡充
- スマホ閲覧最適化（PNG 焼き込みキャッシュ）

### Phase 3
- 簡易 IK（手首・足首ドラッグでチェーン追従）
- 複数マネキン同時配置（構図指示用）
- ポーズを他フレームにコピー
